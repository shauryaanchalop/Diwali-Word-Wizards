## ✨ Flagship Highlights & Interactive Features

### 1. 🎁 The Signature Member Keepsake Card Studio
- **Personalized High-Res Gift**: Generates a high-resolution ($1200 \times 800$) festive member card in real-time on HTML5 Canvas.
- **Official Society Crest**: Features the circular Word Wizards emblem framed in radiant gold filigree.
- **Multi-Department Selection**: Checkbox-style selector supporting members who contribute to multiple wings (e.g. `✦ Technical • Graphics ✦`).
- **One-Click Export**: Instant PNG download for WhatsApp/Instagram status and formatted clipboard greeting copy.

### 3. 🍬 The Legendary Soan Papdi Hamper (सोन पापड़ी का महा-उपहार)
- **The Unstoppable Currency of Diwali**: Flaky, melt-in-the-mouth cardamom cubes garnished with roasted pistachios, almonds, and silver vark.
- **Interactive Cube Relishing**: Click or tap any golden sweet cube in the tray to take a bite with crunchy audio chimes, particle sparkles, and real-time eaten counters (`😋 Relish a Piece!`).
- **The Sacred Regift Relay (`सोन पापड़ी पास करो!`)**: Experience the timeless Indian tradition of regifting across the 9 departments of Word Wizards with funny, customized department banter and an animated relay tracker.
- **Instant Restock**: Refresh and replenish the royal sweet box anytime (`🔄 Restock Sweet Box`).

### 4. 🧨 Virtual Firecracker Simulator (Patakha Arcade)
- **100% Eco-Friendly & Green**: Pure festive celebration with zero smoke or pollution.
- **High-Impact Audio Synthesizer**: Gunpowder snaps, sub-bass 25Hz physical shockwave thump, and continuous sizzle built with native Web Audio API:
  - 🌸 **Anaar (Flowerpot)**: Towering golden fountain with rushing sizzle.
  - 🌀 **Zameen Chakri**: 1200 RPM radial spinning jet with Doppler whirr.
  - 🧨 **1000-Wali Ladi**: Machine-gun rapid-fire gunpowder pops.
  - 💣 **Sutli Bomb**: Screen-shaking sub-bass detonation.
  - 🚀 **Sky Rocket**: Screaming ascending whistle and aerial detonation.
  - ✨ **Phuljhadi**: Crisp sparkling neon crackle.
- **Tap to Burst Anywhere**: Interactive canvas ground responding to mouse clicks and mobile touch taps.

## 🛠️ Technology Stack

- **Frontend Core**: Semantic HTML5, Vanilla JavaScript (ES6+), Modern CSS3 (Glassmorphism, KaTeX & Devanagari typography).
- **Audio Synthesis**: Native Web Audio API (`AudioContext`, `BiquadFilterNode`, `GainNode`, `BufferSource`) with multi-gesture mobile unlock.
- **Graphic Engines**: Dual HTML5 Canvases for celestial starfields, rising festive embers, sparkler wands, and physical firecracker trajectories.
- **Zero Heavy Dependencies**: Completely self-contained, lightning-fast static client loadable anywhere.

## 🚀 Getting Started & Deployment

### Quick Local Run
Simply open `index.html` or `standalone_preview.html` directly in any web browser:
```bash
# On Windows PowerShell
Start-Process "index.html"
```

Or run any local static file server:
```bash
python -m http.server 8000
# Server runs on http://localhost:8000
```
