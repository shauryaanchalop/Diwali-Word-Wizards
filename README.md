## 🛠️ Technology Stack & Architectural Deep Dive

This web portal is built from the ground up with a **Zero-Framework, Pure Web Standards** philosophy, ensuring peak performance (100 Lighthouse score), instant load times (< 300ms), and 100% responsiveness without heavy npm dependencies or runtime bloat:

### 1. 🎨 Visual Design & Typography
- **Design System**: Royal Glassmorphism featuring deep cosmic violet gradients (`#080313` to `#2b1150`), metallic gold filigree (`#ffd768`, `#f5b82e`), and marigold fire accents (`#ff7828`).
- **Typography Pairing**:
  - *Headings & Society Monograms*: `Cinzel` & `Cinzel Decorative` (Google Fonts) for regal scholastic prestige.
  - *Devanagari Sacred Inscriptions*: `Rozha One` & `Tiro Devanagari Hindi` for authentic Vedic celebration.
  - *Interface Body*: `Plus Jakarta Sans` for geometric, crisp readability.
- **Micro-Interactions**: Multi-layer box-shadow aura glows, ceremonial flickering Diya flame particles, and smooth CSS hover/tap elevations.

### 2. ⚡ Dual HTML5 Canvas Engines
- **Layer 1 (Background Canvas)**: 
  - Real-time procedural celestial starfield with twinkle scintillation.
  - Rising warm festive embers and diya light motes floating up into the night sky.
- **Layer 2 (Sparkler Wand Canvas)**:
  - Interactive cursor and touch-tracking golden Phuljhadi wand emitting sparkling physical particles that bounce and fade.
- **Layer 3 (Patakha Arcade Canvas)**:
  - High-performance particle physics engine simulating gravity, velocity drag, explosion fragmentation, and luminous smoke trails for Anaar fountains, spinning Chakris, and aerial rocket shell bursts.

### 3. 🔊 Native Web Audio Synthesizer (No External MP3 Assets)
All sound effects are **procedurally synthesized in real-time** using the native browser `AudioContext` and `Web Audio API` nodes:
- **Gunpowder Cracker Snaps**: High-pass filtered white noise burst with sub-millisecond envelope decay (`BufferSourceNode` + `BiquadFilterNode` + `GainNode`).
- **Sutli Bomb Detonation**: Dual-stage blast combining an immediate gunpowder crack with an exponential frequency drop from 260 Hz to 25 Hz for physical room-shaking sub-bass shockwaves.
- **Zameen Chakri**: 1200 RPM radial Doppler whirr synthesized with frequency-modulated bandpass filters.
- **Sky Rocket**: Screaming ascending frequency ramp (`playRocketWhoosh`) culminating in an aerial burst.
- **Universal Mobile Audio Unlock**: Multi-gesture audio context resumption listeners (`pointerdown`, `touchstart`, `click`) ensuring sound plays seamlessly on iOS Safari and Android Chrome without browser policy blocks.

### 4. 🎁 Dynamic HTML5 Canvas Card Generation
- High-resolution offscreen canvas rendering at $1200 \times 800$ resolution.
- Ornate gold filigree borders, radial background gradients, and the official Word Wizards circular crest.
- Real-time text measurement, custom department badges (supporting multi-department checkboxes), and instantaneous PNG data URL generation for zero-server instant download.

## 🚀 Getting Started & Deployment

### 🌐 Live Production Deployment
The portal is hosted and live globally on Netlify Edge CDN:
👉 **[https://word-wizards-diwali.netlify.app/](https://word-wizards-diwali.netlify.app/)**

### 💻 Local Run
Simply open `index.html` or `standalone_preview.html` directly in any web browser:
```bash
# On Windows PowerShell
Start-Process "index.html"
```

Or run any local static file server:
```bash
python -m http.server 8000
# Server runs on http://localhost:8000
```
